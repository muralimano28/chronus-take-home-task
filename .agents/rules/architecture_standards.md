# Enterprise Software Architecture Rules

You must follow these strict rules for every single response and code generation:

1. **PRODUCTION-GRADE CODE:** Every piece of code generated must be production-ready. This includes robust error handling, edge-case validation, proper logging (not print statements), type safety/hints, and security best practices.
2. **DRY PRINCIPLE:** Strictly adhere to Don't Repeat Yourself (DRY) principles. Abstract repetitive logic into clean, reusable functions, utilities, or components. 
3. **ENTERPRISE STANDARDS:** Ensure modular architecture, clean naming conventions, comprehensive documentation (JSDoc/Docstrings), and optimal performance. Do not provide lazy placeholders or "todo" comments unless explicitly asked.
